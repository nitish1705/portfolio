# Nitish Portfolio

A modern, premium personal portfolio built with React and Vite, showcasing Nitish M’s profile as an iOS & Mobile Engineer, software developer, and competitive programmer.

## Live Demo

**Website:** https://nitishm-portfolio.vercel.app

## Overview

This portfolio is designed as a smooth, scroll-snapped single-page experience with elegant motion, section indicators, analytics cards, and a contact form. It highlights:

- Hero introduction and personal branding
- About section with education details
- Technical arsenal and skills
- Selected projects
- Professional experience
- Competitive programming achievements and live stats
- Contact section with social links and email form

## Features

- Responsive single-page portfolio
- Smooth scroll-snapped sections
- Animated UI with Framer Motion
- Live coding platform stats fetched from external APIs
- Contact form powered by EmailJS
- Resume download support
- Clipboard copy for email address
- Modern card-based layout with premium styling

## Tech Stack

- **Frontend:** React 19, Vite
- **Animation:** Framer Motion
- **Contact Form:** EmailJS
- **Analytics & Charts:** Recharts
- **Deployment:** Vercel
- **Languages:** JavaScript, CSS, HTML

### 1. Hero

## Getting Started

### Prerequisites

- Node.js installed
- npm or yarn

### Installation

```bash
git clone https://github.com/nitish1705/portfolio.git
cd portfolio
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Configuration

### EmailJS
The contact form uses EmailJS. To make it work in your own environment, update the following in `src/App.jsx`:

- `service_5v1vpor`
- `template_vfxvv8f`
- `Q90yjPY0QapVFjvO_`

### Analytics API Sources
The portfolio fetches live stats from:

- LeetCode
- Codeforces
- AtCoder
- GitHub
